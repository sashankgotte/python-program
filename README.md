# Day 2 - Add Two Numbers in Python

## 📌 Project Description

This project is part of my 100 Days of Python Programming Challenge. Day 2 focuses on creating a simple Python program that accepts two numbers from the user and calculates their sum.

The main goal of this program is to understand basic Python input and output operations, integer conversion, and arithmetic operators.

## 🎯 Objectives

- Learn how to accept input from the user.
- Understand the `input()` function.
- Convert string input into integers using `int()`.
- Perform addition using the `+` operator.
- Display the result using the `print()` function.

## 💻 Python Code

```python
a = int(input("Enter first number: "))
b = int(input("Enter second number: "))

print("Sum =", a + b)
```

## ▶️ Sample Output

```text
Enter first number: 10
Enter second number: 20
Sum = 30
```

## ⚙️ How It Works

1. The program asks the user to enter the first number.
2. It asks the user to enter the second number.
3. The `int()` function converts both inputs into integers.
4. The `+` operator adds the two numbers.
5. The `print()` function displays the final sum.
